# Jeffrey Zhang

Security Engineer at [[stripe|Stripe]]. Co-presented "Guardrails Beyond Vibes: Shipping Security Agents in Production" with [[sid-shah|Siddh Shah]] at [[unprompted-conference-march-2026|Unprompted Conference]] (March 3, 2026, Stage 1 Lecture 05).

**LinkedIn:** [j778zhan](https://www.linkedin.com/in/j778zhan)

## Contribution to this wiki

Primary source: [[guardrails-beyond-vibes-talk|Guardrails Beyond Vibes: Shipping Security Agents in Production]]. Zhang is the Security Engineer half of the team; the talk covers two production security agents at Stripe (a threat modeling agent and a security routing agent), their multi-agent architecture, evaluation pipeline design using [[llm-as-a-judge|LLM-as-a-Judge]] with golden-standard test cases, and five operational learnings including the failure of AlphaEvolve for prompt optimization.

Companion Stripe talk at the same conference: [[breaking-the-lethal-trifecta-talk|Breaking the Lethal Trifecta (Without Ruining Your Agents)]] by [[andrew-bullen|Andrew Bullen]] (Head of AI Security at Stripe), delivered the following day.
