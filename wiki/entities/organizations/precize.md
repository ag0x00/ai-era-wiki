# Precize

Precize is credited, on the [AI & Cloud Governance Council's landing page](https://www.aicloudgovernance.com/guides-best-practices/top-10-agentic-ai-security-risks-key-threats-and-mitigation-strategies) for the same initiative, as where the [[precize-agentic-ai-top10|Top 10 for Agentic AI Vulnerability]] taxonomy originated. The GitHub organization `precize` hosts the working repository. That landing page names Vishwas Manral, Ken Huang, and Akram Sherif — the same three editors credited on the GitHub repository — as the initiative's founders and key contributors, so its description of the initiative is self-description on a second platform rather than third-party validation: it states the effort is vendor-neutral ("no money was taken from any vendor"), with more than 50 contributors from over 20 organizations, and calls it "the first industry-wide effort to systematically identify security threats" in agentic AI.

No independent company profile for Precize (product, funding, headcount) has been sourced in this pass; this page records only the project-origination role verifiable from the taxonomy's own repository and landing page.
