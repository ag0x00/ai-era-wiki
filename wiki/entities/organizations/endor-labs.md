# Endor Labs

**Homepage:** [endorlabs.com](https://www.endorlabs.com)

Application-security vendor originating in software-composition analysis and dependency reachability, now selling a governance control plane for AI coding agents. One product carries its relevance here: [[endor-labs-ai-code-governance|AI Code Governance]], a COTS instrument whose unit of analysis is the coding-agent fleet rather than the code the fleet produces.

The company is a vendor, not an advisory or standards body, so under the [[conventions|organization-type rule]] its coined terminology does not by itself justify a concept page. The pattern it implements — inventory and attribution across agentic harnesses — is tracked under existing framings ([[shadow-automation|shadow automation]], [[harness-config-as-supply-chain-artifact|harness config as supply-chain artifact]]) rather than under vendor vocabulary.
