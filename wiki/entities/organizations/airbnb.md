# Airbnb

**Sources:** [Airbnb (homepage)](https://www.airbnb.com) · [Airbnb Tech Blog](https://medium.com/airbnb-engineering)

Hospitality platform (NASDAQ: ABNB). Airbnb contributes to the **security-agent evaluation** discussion through Mudita Khurana (Staff Security Engineer), who presented [[rethinking-security-agent-evaluation-talk|Rethinking How We Evaluate Security Agents for Real-World Use]] at the [[unprompted-conference-march-2026|Unprompted Conference (March 2026)]]. The talk argues for capability-centric evaluation across the **find → confirm exploit → patch → validate** workflow over outcome-only benchmarks.
