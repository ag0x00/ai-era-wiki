# Mate Security

**Sources:** [Mate Security (homepage)](https://mate.security) · [CD/CR framework announcement (blog)](https://mate.security/blog/continuous-detection-continuous-response---a-new-security-operations-framework)

Mate Security is an AI-SOC vendor building agentic detection, investigation, and response on a shared-context substrate it calls the **Security Context Graph** — a living model of organizational knowledge (data lakes, telemetry, SOPs, architecture, Slack, threat intelligence, MITRE ATT&CK) queried where the data lives. Co-founder and CEO Asaf Wiener.

On this wiki Mate appears as one vendor framing of the converged agentic SOC. Its [[mate-cd-cr-continuous-detection-response|CD/CR framework]] (Continuous Detection / Continuous Response) argues that detection, investigation, and response should run as one continuous loop on a single reasoning plane, with closed investigations compressing automatically into new context-specific detections. The framing is directional and vendor-coined; it sits alongside the Microsoft copilot-plus-agents pattern and the [[vulnops-l1-soc-extinction|Mallory "threads, not cases"]] framing in [[agentic-soc-state-of-the-field|Agentic SOC: State of the Field]].
