# Oasis Security

**Sources:** [Oasis Security (homepage)](https://www.oasis.security) · [What Are Non-Human Identities?](https://www.oasis.security/blog/what-are-non-human-identities)

Identity security vendor specializing in **Non-Human Identity (NHI)** management at enterprise scale. Product portfolio centers on NHI discovery, ownership, lifecycle, rotation, and behavioral monitoring across cloud, SaaS, and on-prem.

## Notable Output

- **Blog: What Are Non-Human Identities?** (2026, ingested) — see [[what-are-non-human-identities|What Are Non-Human Identities? (Oasis Security)]]. Argues NHIs are a structurally distinct governance class; introduces the identity-credential-coupling framing for SAS tokens / storage keys / PATs; documents the HR-vs-code-pace IAM lifecycle mismatch.
- **Comprehensive Guide to Non-Human Identity Management** (referenced in the blog post; not yet ingested).
- Glossary entries on Service Principal, Service Account, OAuth 2.0, MFA.
- Research on Microsoft Azure MFA bypass.

## Placement in the [[agentic-ai-security-reference-architecture|Agentic AI Security Reference Architecture]]

Identity plane (D2) — NHI discovery, ownership, lifecycle, behavioral monitoring. Closest peers: Aembit, Astrix Security, CyberArk Conjur, Okta NHI / Okta for AI Agents. Where Oasis emphasizes NHIs broadly (machine identities at enterprise scale), Okta for AI Agents and Microsoft Agent 365 emphasize agent-specific governance — they cover overlapping ground from different starting points.
